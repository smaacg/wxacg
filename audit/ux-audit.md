# 使用者體驗與介面稽核 (UX Audit)

AdSense 的「網站管理員品質指南」不僅看內容字數，也高度看重網站的排版與使用者體驗。

## 1. 版面與廣告配置衝突
* **現狀**: 為了提升收益，許多網站會在首屏（Above the fold）放置大型廣告。
* **風險**: 如果第一眼看到的只有廣告與大張的海報圖片，沒有實質文字內容，AdSense 審查員會直接判定為 Thin Content。
* **解法**: 
  * 確保文章標題下方、第一段內容上方**不要**有過大的廣告區塊。
  * 內容才是主角，廣告必須是配角。

## 2. 動漫作品頁的閱讀體驗
* **現狀**: 目前 single-anime.php 將所有資料全數展開。
* **解法**:
  * 核心觀看資訊（串流平台、年份、集數）應該在**最顯眼的位置**（首屏）。
  * 大量的 Staff 名單、長篇的關聯作品列表，應該使用**折疊區塊 (Accordion/Tabs)** 或是放在頁面較下方，避免喧賓奪主，妨礙核心介紹的閱讀。
  * 強調「人工編輯的推薦語」，用引言區塊 (Blockquote) 或特殊底色標示，讓使用者一眼看出這是網站專屬的特色內容。

## 3. 行動裝置適配 (Mobile First)
* **檢查項目**:
  * 表格與多欄位排版在手機上是否會破版？
  * 點擊元素（標籤、集數按鈕）是否夠大？
  * 圖片是否都已啟用 Lazy Loading (延遲載入) 以提升 Core Web Vitals (特別是 LCP)？
* **解法**: 必須確保 Blocksy 佈景主題的行動版設定完全優化，避免 CLS (版面位移) 過高。

## 4. 明確的網站目的宣告
* **問題**: 第一次進來的訪客（包含審查員），知道這個網站是在幹嘛的嗎？
* **解法**: 
  * 確保首頁或 Footer 有清楚的「關於我們 / 網站簡介」。
  * 明確定位：「微笑動漫提供最新季番資訊、合法串流觀看指南與深度動漫新聞...」
  * 增加網站的公信力 (E-E-A-T 因素)。
