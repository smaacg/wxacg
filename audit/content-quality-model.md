# 內容價值分級模型 (Content Quality Model)

基於 AdSense「提供獨特且優質的內容」的政策，我們將網站的頁面劃分為以下五個等級。未來的 SEO 與 AdSense 申請策略將以此為基礎。

## 分級定義

* **A：高價值頁面 (High Value)** - 擁有大量原創編輯內容、獨特觀點、無可取代的在地化資訊。Google 應該優先索引。
* **B：有價值但需要補強 (Needs Enrichment)** - 結構正確，但目前高度依賴第三方資料，必須加上原創資料層才能升級為 A。
* **C：低價值 (Low Value)** - 內容稀少、單一，對使用者的幫助極小，容易被判定為 Thin Content。
* **D：應該 noindex (Noindex Target)** - 結構上必須存在（如搜尋結果），但絕對不該讓 Google 爬蟲抓取，會嚴重拉低網站整體品質分數。
* **E：應該刪除 / redirect (Delete/Redirect)** - 錯誤產生、冗餘或無意義的頁面。

## 頁面類型分級判定

### 1. 動漫單頁 (`/anime/{slug}/`) - 目前等級：B
* **現狀**：擁有詳細的 CAST、Staff、評分，但全為 API 同步資料。
* **升級方案**：必須加入「微笑動漫編輯摘要」、「台灣/香港在地串流平台資訊」、「觀看指南（如：觀看順序）」等原創內容。

### 2. 新聞文章 (`/news/` / `post`) - 目前等級：A / B (視內容而定)
* **現狀**：如果是編輯親自撰寫的觀點文章，屬於 A。如果是直接翻譯或 AI 改寫的新聞，屬於 B。
* **升級方案**：新聞必須附加關聯的動漫庫連結（Knowledge Graph），並加入「事件背景分析」而非單純翻譯。

### 3. 季番列表頁 (`/season/`) - 目前等級：B
* **現狀**：提供當季動畫列表，有工具價值（查詢新番），但缺乏內容深度。
* **升級方案**：加入「本季必看推薦」、「編輯部期待度排行」、「每週更新時間表」等人工策展內容。

### 4. 角色與人物頁 (`/character/`, `/person/`) - 目前等級：C (部份 D)
* **現狀**：大多只有名字與外觀，缺乏生平或詳細介紹。
* **處置方案**：如果外部 API 抓不到大於 50 字的簡介，自動歸類為 **D (noindex)**。如果有長篇簡介，則保持 C，並鼓勵使用者留言或補充，逐步提升為 B。

### 5. 標籤頁 (`/tag/`) 與 分類頁 (`/category/`) - 目前等級：C / D
* **現狀**：標籤過多 (1634個)，導致大量標籤頁只有 1 篇文章。
* **處置方案**：文章數小於 3 篇的標籤頁一律 **D (noindex)**。核心分類頁必須加入人工撰寫的「分類介紹」。

### 6. 排行榜 (`/ranking/`) - 目前等級：B
* **現狀**：依照第三方評分排名的頁面，有工具價值。
* **升級方案**：除了冷冰冰的分數，可以加入「微笑動漫編輯評語」或是「社群熱度指標」。

### 7. 系統/功能性頁面 - 目前等級：D
* **名單**：搜尋結果頁 (`/search/`)、API endpoints、JSON feeds、登入/註冊頁。
* **處置方案**：嚴格執行 **noindex**。

## 核心轉型策略

我們不能只當「繁體中文版的 AniList」，我們必須成為「提供台灣/華語圈最實用觀看資訊的動漫入口」。
**所有的 B 級頁面，都必須透過第四階段的「微笑動漫原創資料層」升級為 A 級頁面。**
