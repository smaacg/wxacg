# AdSense 重新申請前檢查清單 (AdSense Ready Checklist)

在將網站提交給 Google 重新審查前，必須 100% 確認以下項目皆已達標。

## 🎯 核心價值與定位 (Value Proposition)
- [ ] 網站首頁與 Footer 有清楚說明網站目的與服務內容。
- [ ] 網站具有足夠的「原創編輯價值」，而非純粹的資料庫鏡像。
- [ ] 沒有為了增加頁面數量而大量生成毫無意義的垃圾頁面。

## 📝 內容品質 (Content Quality)
- [ ] 主要動漫作品頁 (Anime) 已經加入「微笑動漫編輯摘要」或在地化觀看指南。
- [ ] 新聞文章 (News) 具備編輯觀點、事件背景，並非單純機器翻譯。
- [ ] 沒有大量字數極少（例如少於 50 字）的空白文章被索引。
- [ ] 內容來源透明，有標示第三方 API 資料來源，並與本站原創內容有明確區隔。

## 🕷️ 索引與架構 (Indexing & Structure)
- [ ] 已經全面實施 `noindex` 於低價值頁面（如：無簡介的虛擬角色頁、空分類、空標籤）。
- [ ] `robots.txt` 已封鎖不必要的系統與參數路徑 (`/?s=`, `/wp-json/` 等)。
- [ ] XML Sitemap 只包含準備好被索引的高價值頁面 (A/B 級)。
- [ ] 內部連結架構完善，新聞與動漫作品、系列作之間有雙向導航 (無孤兒頁面)。
- [ ] Taxonomy (分類/標籤) 已清理，沒有大量只有 1 篇文章的無用標籤。

## 🛠️ 技術與使用者體驗 (Technical & UX)
- [ ] 404 錯誤頁面處理正常，不會無限重新導向。
- [ ] Canonical 標記設定正確，無重複內容衝突。
- [ ] Mobile UX (行動裝置體驗) 良好，點擊區塊大小合適，無破版。
- [ ] 首屏 (Above the fold) 內容為主，沒有被超大廣告佔滿版面。

## 📜 法律與信任條款 (Trust & Legal) - 非常重要！
- [ ] **About Us (關於我們)** 頁面完整，說明網站團隊與成立目的。
- [ ] **Contact Us (聯絡我們)** 頁面正常運作，提供實際聯絡方式。
- [ ] **Privacy Policy (隱私權政策)** 完整，且包含 Cookie / AdSense 相關聲明。
- [ ] **Terms of Use (使用條款)** 完整。
- [ ] 版權宣告清楚，第三方圖片/資料來源有適當免責或引用說明。
